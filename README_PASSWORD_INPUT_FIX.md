# 비밀번호 입력 잠김 수정

포함된 Supabase SDK는 initialize()가 완료된 뒤 setTimeout으로 PASSWORD_RECOVERY 이벤트를 전달합니다.
이전 코드가 initialize 직후 이벤트가 없다는 이유로 유효한 이메일 링크를 거부하던 문제를 수정했습니다.
이제 최대 5초 동안 이벤트를 기다린 다음 서버 사용자 확인을 거쳐 입력을 허용합니다.
이벤트 콜백 내부에서는 추가 Auth 호출을 하지 않습니다.

## 적용
이 ZIP은 이메일 등록 수정도 포함한 전체본입니다.
직전 이메일 등록 수정본을 이미 배포했다면 js/cloud.js와 HTML 파일들을 GitHub에 교체하면 됩니다.
HTML의 버전 문자열도 바뀌었으므로 함께 반영해야 이전 JS 캐시가 갱신됩니다.
이 입력 잠김 수정 자체에는 Supabase 함수 재배포가 필요 없습니다.
이메일 등록용 admin-users 함수를 아직 업데이트하지 않았다면 README_EMAIL_REGISTRATION.md를 따르세요.

배포 완료 후 로그인 화면에서 Ctrl+F5를 누르고 새 재설정 이메일을 요청합니다.
가장 최근 이메일 링크로 접속하고 새로고침하지 않은 상태에서 비밀번호를 입력합니다.
직접 주소 접근, 만료/사용된 링크, 일반 로그인 세션은 여전히 재설정 인증으로 인정되지 않습니다.

검증: 실제 번들 SDK의 이벤트 전달 방식 확인, 같은 비동기 순서로 재현한 회귀 테스트 통과.
지연 이벤트 수신 성공, 일반 세션 및 복구 이벤트 없음 차단, 비밀번호 변경 호출 검증.
전체 JavaScript 문법 및 기존 데이터 동기화 보존 검사 통과.
운영 사이트의 실제 이메일 링크 테스트와 배포는 수행하지 않았습니다.
